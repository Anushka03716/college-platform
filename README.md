## CollegeHub – College Review & Exploration Platform

A full-stack web application where users can explore colleges, save favorites, and share reviews.

---

## Live Demo

* Frontend: [https://college-platform.vercel.app](https://college-platform.vercel.app)
* Backend: [https://college-backend-ruwx.onrender.com](https://college-backend-ruwx.onrender.com)

---

## Features

* User Authentication (Login/Register)
* Browse Colleges with filters & sorting
* View College Details
* Add & View Reviews
* Save Colleges
* Filter by Location & Fees
* Responsive UI

---

## Tech Stack

### Frontend

* Next.js (App Router)
* React
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MySQL (Railway)

### Deployment

* Vercel (Frontend)
* Render (Backend)

## Run Locally

### 1. Clone repo

```bash
git clone https://github.com/Anushka03716/college-platform.git
cd college-platform
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Start frontend

```bash
npm run dev
```

---

### 4. Start backend

```bash
cd backend
node index.js
```
