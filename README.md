# CollegeHub

CollegeHub is a full-stack web application that helps students explore, compare, and review colleges in one place.  
It provides structured data along with user-generated insights to support better decision-making.

---

## Features

- Search and filter colleges by name, location, and fees  
- View ratings and detailed college information  
- Save colleges for later  
- Add and view user reviews  
- Compare two colleges side-by-side  
- User authentication (Login/Register)  
- Fully deployed (Frontend + Backend)

---

## Tech Stack

### Frontend
- Next.js (App Router)
- React
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL (Railway)

### Deployment
- Vercel (Frontend)
- Render (Backend)
